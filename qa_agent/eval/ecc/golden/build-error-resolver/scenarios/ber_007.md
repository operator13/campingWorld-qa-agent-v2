# Scenario: API Changed in Newer Package Version

## Code File: `src/middleware/logger.ts`

```typescript
import winston from "winston";

const logger = winston.createLogger({
  level: "info",
  format: winston.format.combine(
    winston.format.timestamp(),
    winston.format.json()
  ),
  transports: [
    new winston.transports.Console(),
    new winston.transports.File({ filename: "app.log" }),
  ],
});

// This method was removed in winston 4.x
logger.log("info", "Application started", { pid: process.pid });
logger.query({ from: new Date() - 24 * 60 * 60 * 1000 }, (err, results) => {
  if (err) throw err;
  console.log(results);
});

export { logger };
```

## Task

Fix the build errors. The `logger.query()` callback API changed in winston 4.x — it now returns a Promise-based interface. Also, `new Date() - number` is not valid in TypeScript strict mode; use `new Date(Date.now() - 24 * 60 * 60 * 1000)` instead.
