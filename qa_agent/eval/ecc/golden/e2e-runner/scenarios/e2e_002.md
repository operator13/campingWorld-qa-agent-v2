# Scenario: Generate Playwright test for product search and filter

## Task
Generate a Playwright spec and Page Object for the product search and filter flow.

## Page Description
The search page at `/search` contains:
- Search input in the header (`data-testid="search-input"`)
- Search submit button (magnifying glass icon, role="button", name="Search")
- Results grid with product cards (`data-testid="product-card"`)
- Each card has: product title, price, "Add to Cart" button
- Filter sidebar with:
  - Category checkboxes (e.g., "RVs", "Camping Gear", "Outdoor Living")
  - Price range slider (`data-testid="price-min"`, `data-testid="price-max"`)
  - "Apply Filters" button
- Results count text: "Showing X of Y results"

## Expected Behavior
- Typing "tent" and submitting shows filtered results
- Checking "Camping Gear" narrows results to that category
- Setting price range 50-200 filters by price
- Results count updates after each filter

## Expected Output
- `page_objects/SearchPage.ts` with locators and action methods
- `tests_generated/search.spec.ts` with search and filter tests
