# Scenario: Generate Playwright test for user registration flow

## Task
Generate a Playwright spec and Page Object for the campingworld.com registration page.

## Page Description
The registration page at `/create-account` contains:
- First Name input (required, `data-testid="first-name"`)
- Last Name input (required, `data-testid="last-name"`)
- Email input (required, validates email format, `data-testid="email"`)
- Password input (required, min 8 chars, `data-testid="password"`)
- Confirm Password input (must match password, `data-testid="confirm-password"`)
- "Create Account" submit button
- On success: redirects to `/account/dashboard` with welcome banner

## Validation Rules
- Empty required fields show inline error: "This field is required"
- Invalid email shows: "Please enter a valid email"
- Password mismatch shows: "Passwords do not match"

## Expected Output
- `page_objects/RegisterPage.ts` with locators and action methods
- `tests_generated/register.spec.ts` with happy-path and validation tests
