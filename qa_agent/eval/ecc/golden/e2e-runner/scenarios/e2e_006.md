# Scenario: Broken locator - element restructured

## Task
Update the Page Object after a DOM restructure broke a CSS-based locator.

## Error
```
Error: locator.click: Error: strict mode violation:
  locator('.sidebar > ul > li:nth-child(2) > a') resolved to 0 elements
  at NavigationPage.goToCategory (page_objects/NavigationPage.ts:18:38)
```

## Current Page Object (broken)
```typescript
// page_objects/NavigationPage.ts
import { Page, Locator } from '@playwright/test';

export class NavigationPage {
  readonly page: Page;
  readonly logo: Locator;
  readonly campingGearLink: Locator;
  readonly rvPartsLink: Locator;

  constructor(page: Page) {
    this.page = page;
    this.logo = page.getByTestId('site-logo');
    this.campingGearLink = page.locator('.sidebar > ul > li:nth-child(2) > a');
    this.rvPartsLink = page.locator('.sidebar > ul > li:nth-child(3) > a');
  }

  async goToCategory(link: Locator) {
    await link.click();
  }
}
```

## What Changed
The sidebar navigation was refactored from a flat `<ul>` to a nested
`<nav>` with `<details>` / `<summary>` accordion. The old CSS selectors
no longer match. The new structure uses `role="navigation"` and each link
has accessible text like "Camping Gear" and "RV Parts & Accessories".

## Expected Fix
Replace the brittle CSS selectors with `getByRole('link', { name: '...' })`
or use `data-testid` attributes. The fix should be resilient to future
DOM changes.
