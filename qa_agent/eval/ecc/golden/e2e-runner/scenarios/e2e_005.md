# Scenario: Broken locator - button text changed

## Task
Update the Page Object after the "Add to Cart" button text was changed to "Add to Bag".

## Error
```
Error: locator.click: Error: strict mode violation:
  getByRole('button', { name: 'Add to Cart' }) resolved to 0 elements
  at ProductPage.addToCart (page_objects/ProductPage.ts:14:42)
```

## Current Page Object (broken)
```typescript
// page_objects/ProductPage.ts
import { Page, Locator } from '@playwright/test';

export class ProductPage {
  readonly page: Page;
  readonly productTitle: Locator;
  readonly price: Locator;
  readonly addToCartButton: Locator;
  readonly quantityInput: Locator;

  constructor(page: Page) {
    this.page = page;
    this.productTitle = page.getByTestId('product-title');
    this.price = page.getByTestId('product-price');
    this.addToCartButton = page.getByRole('button', { name: 'Add to Cart' });
    this.quantityInput = page.getByTestId('quantity');
  }

  async addToCart() {
    await this.addToCartButton.click();
  }
}
```

## What Changed
The button text on the product detail page was updated from "Add to Cart"
to "Add to Bag" in a recent redesign. The `data-testid` was not added.

## Expected Fix
Update the locator in `ProductPage.ts` to use the new button text "Add to Bag".
