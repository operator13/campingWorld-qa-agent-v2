# Task: Shopping Cart Price Calculator with Discounts

## Context

The checkout flow needs a price calculator that takes a list of cart items and optional discount codes, then returns the final price. The current implementation is a monolithic function with no tests — it needs to be rewritten test-first.

## Data Structures

```python
@dataclass
class CartItem:
    product_id: str
    name: str
    unit_price: Decimal
    quantity: int

@dataclass
class Discount:
    code: str
    type: str          # "percentage" or "fixed"
    value: Decimal     # percentage (0-100) or fixed dollar amount
    min_order: Decimal # minimum order total to apply
```

## File Location

Create `app/services/cart_calculator.py` with `calculate_total(items: list[CartItem], discounts: list[Discount]) -> Decimal`.

## Business Rules

- Items total = sum of (unit_price * quantity) for each item
- Percentage discounts apply to the subtotal before fixed discounts
- Fixed discounts are subtracted after percentage discounts
- Total can never go below $0.00
- Discounts with min_order above the current subtotal are skipped
- Multiple percentage discounts stack multiplicatively (not additively)
