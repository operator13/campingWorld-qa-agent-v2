# Task: Fix Off-by-One Error in Pagination

## Bug Report

Users report that when browsing products with 20 items per page, the last page sometimes shows 0 results even though there are remaining items. For example, with 41 products and limit=20, page 3 returns empty instead of the 41st product.

## Current Implementation

```python
def paginate(items: list, page: int, limit: int) -> dict:
    total = len(items)
    total_pages = total // limit  # BUG: should use ceiling division
    start = (page - 1) * limit
    end = start + limit
    return {
        "items": items[start:end],
        "total": total,
        "page": page,
        "limit": limit,
        "pages": total_pages,
    }
```

## File Location

- Source: `app/utils/pagination.py`
- Tests: `tests/test_pagination.py`

## Expected Fix

- `total_pages` should use ceiling division: `math.ceil(total / limit)`
- Requesting a page beyond total_pages should return empty items (not error)
- Page 0 or negative page should raise ValueError

## What to Test First

Write a regression test that calls `paginate(range(41), page=3, limit=20)` and asserts exactly 1 item is returned.
