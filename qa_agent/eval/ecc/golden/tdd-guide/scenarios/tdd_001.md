# Task: String Validation Utility for Product SKUs

## Context

The e-commerce platform uses SKU codes to identify products. SKUs follow a strict format but the current codebase has no centralized validation — each module checks format ad hoc, leading to inconsistent enforcement and invalid SKUs reaching the database.

## SKU Format Rules

- Must be exactly 10 characters long
- Format: `[A-Z]{2}-[0-9]{4}-[A-Z]{2}` (e.g., `RV-1234-AB`)
- First two letters: category code (must be in allowed set: RV, TN, AC, PT, EL)
- Middle four digits: sequential product number (0001-9999)
- Last two letters: warehouse code (any uppercase pair)

## File Location

Create `app/utils/sku_validator.py` with a function `validate_sku(sku: str) -> tuple[bool, str]` that returns `(True, "")` on success or `(False, "reason")` on failure.

## What to Test

- Valid SKUs for each category code
- Invalid category codes, wrong length, missing hyphens
- Edge cases: None, empty string, lowercase input, unicode characters
