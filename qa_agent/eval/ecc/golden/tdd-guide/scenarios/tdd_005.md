# Task: Extract Authentication Logic from Request Handler

## Context

The login endpoint handler contains 60 lines of inline authentication logic: password hashing, token generation, rate limiting, and audit logging. This makes it untestable without standing up the full HTTP server. The auth logic should be extracted into a standalone module.

## Current Implementation (simplified)

```python
@router.post("/login")
async def login(request: Request, body: LoginRequest, db: Session = Depends(get_db)):
    user = db.query(User).filter(User.email == body.email).first()
    if not user:
        raise HTTPException(status_code=401, detail="Invalid credentials")

    if not bcrypt.checkpw(body.password.encode(), user.password_hash.encode()):
        user.failed_attempts += 1
        if user.failed_attempts >= 5:
            user.locked_until = datetime.utcnow() + timedelta(minutes=15)
        db.commit()
        raise HTTPException(status_code=401, detail="Invalid credentials")

    if user.locked_until and user.locked_until > datetime.utcnow():
        raise HTTPException(status_code=403, detail="Account locked")

    token = jwt.encode({"sub": user.id, "exp": datetime.utcnow() + timedelta(hours=1)}, SECRET)
    user.failed_attempts = 0
    user.last_login = datetime.utcnow()
    db.commit()
    return {"access_token": token}
```

## File Locations

- Current: `app/routers/auth.py` (handler with inline logic)
- Target: `app/services/auth_service.py` (extracted module)
- Tests: `tests/test_auth_service.py`

## What to Test

Write tests for the extracted `AuthService` class methods: `authenticate(email, password)`, `check_lockout(user)`, `generate_token(user)`, `record_failed_attempt(user)`. Tests should not require FastAPI or a real database.
