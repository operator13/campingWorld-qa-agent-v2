# Task: Replace Callback Pattern with Async/Await

## Context

The payment processing module uses a callback-based pattern inherited from an older SDK. The rest of the codebase has moved to async/await. The callback nesting makes error handling fragile and the code hard to follow.

## Current Implementation

```python
def process_payment(order_id: str, amount: float, callback):
    def on_validate(valid, error):
        if error:
            callback(None, error)
            return
        if not valid:
            callback(None, ValueError("Invalid payment details"))
            return

        def on_charge(charge_id, error):
            if error:
                callback(None, error)
                return

            def on_record(receipt, error):
                if error:
                    # charge succeeded but recording failed — log for reconciliation
                    logger.error(f"Orphaned charge {charge_id}: {error}")
                    callback(None, error)
                    return
                callback(receipt, None)

            record_transaction(order_id, charge_id, amount, on_record)

        charge_card(order_id, amount, on_charge)

    validate_payment(order_id, amount, on_validate)
```

## File Locations

- Current: `app/payments/processor.py`
- Target: `app/payments/async_processor.py`
- Tests: `tests/test_async_processor.py`

## What to Test

Write async tests that verify: successful payment flow, validation failure, charge failure, recording failure with orphaned charge logging. Ensure the async version produces identical results to the callback version for all cases.
