# Task: File Upload with Size and Type Validation

## Context

The platform allows users to upload product images and documents (warranty PDFs, manuals). Currently there is no server-side validation — the frontend checks file type and size but these are trivially bypassed. A malicious user recently uploaded a 2GB file that exhausted disk space.

## Requirements

- Allowed image types: JPEG, PNG, WebP (validated by magic bytes, not just extension)
- Allowed document types: PDF (validated by magic bytes)
- Maximum file size: 10MB for images, 25MB for documents
- Minimum file size: 1 byte (reject zero-byte files)
- File names must be sanitized (no path traversal, no special characters)
- Return specific error messages: "File too large (10.5MB, max 10MB)", "Invalid file type: expected JPEG/PNG/WebP, got GIF"

## File Location

Create `app/utils/file_validator.py` with `validate_upload(file_bytes: bytes, filename: str, category: str) -> tuple[bool, str]` where category is "image" or "document".

## Magic Bytes Reference

- JPEG: `FF D8 FF`
- PNG: `89 50 4E 47`
- WebP: `52 49 46 46` ... `57 45 42 50`
- PDF: `25 50 44 46`

## What to Test

Write tests covering: valid JPEG, valid PNG, valid WebP, valid PDF, oversized image, zero-byte file, renamed .exe with .jpg extension, path traversal in filename (`../../etc/passwd.jpg`), exactly 10MB image (boundary), 10MB + 1 byte image.
