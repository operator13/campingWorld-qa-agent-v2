# Task: Currency Conversion with Rounding Rules

## Context

The e-commerce platform is expanding internationally and needs a currency conversion utility. Financial accuracy is critical — rounding errors accumulate and cause reconciliation issues. The accounting team requires banker's rounding (round half to even) and all calculations must use `Decimal` to avoid IEEE 754 floating-point artifacts.

## Requirements

- Convert between any two supported currencies using exchange rates
- Supported currencies: USD, EUR, GBP, CAD, AUD, JPY
- Exchange rates provided as a dict mapping currency pairs to rates
- Use `Decimal` for all internal calculations (no `float`)
- Apply banker's rounding (ROUND_HALF_EVEN) to 2 decimal places (0 for JPY)
- Support inverse conversion: if USD->EUR rate is 0.92, EUR->USD is 1/0.92
- Support chained conversion: EUR->GBP via EUR->USD->GBP when no direct rate exists
- Zero amount should return zero in target currency
- Negative amounts should raise ValueError

## File Location

Create `app/utils/currency.py` with:
- `convert(amount: Decimal, from_currency: str, to_currency: str, rates: dict) -> Decimal`

## What to Test

Write tests for: standard USD->EUR, inverse EUR->USD, same-currency returns same amount, JPY rounds to 0 decimals, banker's rounding (2.5 -> 2, 3.5 -> 4), sub-cent amounts (0.001 USD), large amounts ($1M+), chained conversion, missing rate pair raises error, negative amount raises ValueError.
