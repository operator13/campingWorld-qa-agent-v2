# Scenario: Live code - export used by external package (decoy)

## Task
Analyze `src/lib/validators.ts` for unused exports.

## File: src/lib/validators.ts
```typescript
export function isValidEmail(email: string): boolean {
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}

export function isValidPhone(phone: string): boolean {
  return /^\+?[\d\s\-()]{7,15}$/.test(phone);
}
```

## Internal codebase usage (grep results)
```
$ grep -r "isValidEmail" src/ tests/
src/lib/validators.ts:1:  export function isValidEmail
src/components/ContactForm.tsx:2: import { isValidEmail } from '../lib/validators';
```

## Public API evidence
```
$ cat src/index.ts
export { isValidEmail, isValidPhone } from './lib/validators';
export { CacheService } from './services/cache';
```

## Expected Finding
`isValidPhone` has no direct internal import, but it IS re-exported from
`src/index.ts` as part of the public API. External consumers may depend
on it. It must NOT be removed. The agent should flag it as public API
and leave it in place.
