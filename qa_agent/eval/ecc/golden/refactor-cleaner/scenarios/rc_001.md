# Scenario: Unused exported function

## Task
Analyze `utils/date-helpers.ts` for dead code. Remove any exports that have no importers.

## File: utils/date-helpers.ts
```typescript
export function formatDate(date: Date): string {
  return date.toISOString().split('T')[0];
}

export function formatLegacyDate(date: Date): string {
  const m = date.getMonth() + 1;
  const d = date.getDate();
  const y = date.getFullYear();
  return `${m}/${d}/${y}`;
}

export function isToday(date: Date): boolean {
  const now = new Date();
  return formatDate(date) === formatDate(now);
}
```

## Codebase usage (grep results)
```
src/components/Header.tsx:  import { formatDate } from '../utils/date-helpers';
src/pages/Dashboard.tsx:    import { formatDate, isToday } from '../utils/date-helpers';
```

## Expected Finding
`formatLegacyDate` is exported but never imported anywhere. It should be
removed or have its `export` keyword removed.
