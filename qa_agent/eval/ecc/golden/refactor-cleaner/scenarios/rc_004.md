# Scenario: Duplicate function in two files

## Task
Analyze these two files for duplicated logic and consolidate.

## File: qa_agent/nodes/planner.py
```python
import re

def make_slug(text: str) -> str:
    """Convert text to URL-safe slug."""
    text = text.lower().strip()
    text = re.sub(r"[^\w\s-]", "", text)
    text = re.sub(r"[\s_]+", "-", text)
    return re.sub(r"-+", "-", text).strip("-")

def plan_tests(spec: dict) -> list:
    slug = make_slug(spec["title"])
    return [{"id": f"tc-{slug}-{i}", "step": s} for i, s in enumerate(spec["steps"])]
```

## File: qa_agent/nodes/generator.py
```python
import re

def slugify(title: str) -> str:
    """Turn a title into a slug."""
    title = title.lower().strip()
    title = re.sub(r"[^\w\s-]", "", title)
    title = re.sub(r"[\s_]+", "-", title)
    return re.sub(r"-+", "-", title).strip("-")

def generate_filename(title: str) -> str:
    return f"{slugify(title)}.spec.ts"
```

## Expected Finding
`make_slug` and `slugify` are identical logic with different names.
Extract to a shared utility (e.g., `qa_agent/utils/text.py`) and
import from both files.
