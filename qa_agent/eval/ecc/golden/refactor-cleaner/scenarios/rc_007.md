# Scenario: Dev dependency orphaned after test file deleted

## Task
Analyze `package.json` devDependencies for orphaned packages.

## File: package.json (excerpt)
```json
{
  "devDependencies": {
    "vitest": "^1.6.0",
    "sinon": "^17.0.0",
    "@types/sinon": "^17.0.3"
  }
}
```

## Codebase import search (grep results)
```
$ grep -r "sinon" src/ tests/ tests_generated/ page_objects/
(no results)

$ grep -r "vitest" tests/
tests/unit/cache.test.ts: import { describe, it, expect } from 'vitest';
tests/unit/format.test.ts: import { describe, it, expect } from 'vitest';
```

## Git log context
```
$ git log --oneline --diff-filter=D -- "tests/**sinon**"
a3f91c2 chore: remove legacy stub tests in favor of vitest mocks
```

## Expected Finding
`sinon` and `@types/sinon` are devDependencies that were only used in a
test file deleted in commit a3f91c2. No remaining code imports sinon.
Both packages should be removed from devDependencies. `vitest` is still
actively used.
