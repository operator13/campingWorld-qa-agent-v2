# Scenario: Live code - dependency used via dynamic import (decoy)

## Task
Analyze `package.json` dependencies for unused packages.

## File: package.json (excerpt)
```json
{
  "dependencies": {
    "express": "^4.18.2",
    "sharp": "^0.33.2",
    "multer": "^1.4.5"
  }
}
```

## Static import search (grep results)
```
$ grep -r "from 'sharp'" src/
(no results)

$ grep -r "require('sharp')" src/
(no results)

$ grep -r "from 'express'" src/
src/server.ts: import express from 'express';

$ grep -r "from 'multer'" src/
src/routes/upload.ts: import multer from 'multer';
```

## Dynamic import search
```
$ grep -r "import('sharp')" src/
src/services/image-processor.ts:  const sharp = await import('sharp');
```

## File: src/services/image-processor.ts
```typescript
export async function resizeImage(buffer: Buffer, width: number): Promise<Buffer> {
  const sharp = await import('sharp');
  return sharp.default(buffer).resize(width).toBuffer();
}
```

## Expected Finding
`sharp` appears unused in static imports but IS used via `import()` in
`image-processor.ts`. This is a dynamic import for lazy loading. The
dependency is live and must NOT be removed.
