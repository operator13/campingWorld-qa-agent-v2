# Scenario: Unused exported class

## Task
Analyze `services/report-generators.ts` for dead code. Remove unused classes.

## File: services/report-generators.ts
```typescript
export class HtmlReportGenerator {
  generate(data: Record<string, unknown>[]): string {
    return `<table>${data.map(r =>
      `<tr>${Object.values(r).map(v => `<td>${v}</td>`).join('')}</tr>`
    ).join('')}</table>`;
  }
}

export class XmlReportGenerator {
  generate(data: Record<string, unknown>[]): string {
    return `<report>${data.map(r =>
      `<row>${Object.entries(r).map(([k, v]) =>
        `<${k}>${v}</${k}>`).join('')}</row>`
    ).join('')}</report>`;
  }
}
```

## Expected Finding
`XmlReportGenerator` is never imported anywhere. It is dead code and
should be removed.
