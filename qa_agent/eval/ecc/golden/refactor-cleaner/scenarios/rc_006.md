# Scenario: Unused dependency in package.json

## Task
Analyze `package.json` dependencies for packages that are never imported.

## File: package.json (excerpt)
```json
{
  "dependencies": {
    "dayjs": "^1.11.10",
    "moment": "^2.30.1",
    "playwright": "^1.52.0"
  }
}
```

## Codebase import search (grep results)
```
$ grep -r "from 'moment'" src/ tests_generated/ page_objects/
(no results)

$ grep -r "require('moment')" src/ tests_generated/ page_objects/
(no results)

$ grep -r "from 'dayjs'" src/ tests_generated/ page_objects/
src/utils/format-date.ts: import dayjs from 'dayjs';

$ grep -r "from 'playwright'" tests_generated/ page_objects/
tests_generated/cart.spec.ts: import { test, expect } from '@playwright/test';
page_objects/CartPage.ts: import { Page } from '@playwright/test';
```

## Expected Finding
`moment` is listed as a dependency but is never imported anywhere in the
codebase. It should be removed from `package.json`. `dayjs` and
`playwright` are actively used.
